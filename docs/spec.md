# Marketing Site — Spec

Status: STUB. Awaiting the marketing site brainstorm session.

## Goal

Marketing page announcing the store before the Shopify storefront opens. Generate curiosity, capture interested visitors, build SEO foundation.

## Open for brainstorming

- Single page vs multi-page
- Content blocks / sections
- Email capture: yes or no; welcome flow design
- Swedish, English, or both
- Interactive elements — countdown, teaser, product sneak peeks
- Launch-state transition — does the landing page redirect to the Shopify store at launch, or live alongside?

## Explicitly not in scope

- E-commerce functionality — that belongs in the Shopify store
- Inventory management
- User accounts
